# 中国大陆国行 Android 手机系统组件“脱毒”笔记

> **项目定位**：这是一个**个人自用的小范围研究与实机排雷笔记**，围绕作者手头两台国行手机的实际需求展开，公开出来仅供同好参考与技术交流，并非面向所有机型的通用教程或一键清理工具。

2026-11-20。针对移动终端的系统级反诈、应用扫描与遥测，最省心的办法是直接用外版设备（Pixel、外版 iPhone / 三星），或者在支持解锁 Bootloader 的手机上直接刷入 **LineageOS** 等开源类原生系统（或官方 Global 国际版固件），从根源上换掉整套国行特权框架。

做这个仓库本身是**妥协之下的止损方案**——当手头的机器因为厂商封锁 BL 解锁、联发科天玑平台缺乏稳定 LineageOS 设备树，或因为已经存了太多核心数据（Passkey、唯一登录会话、钱包密钥等）不便原地洗机时，只能在原厂国行 Android/AOSP 固件（含仍兼容 Android 包管理的 EMUI、HarmonyOS 2/3/4.x；不含 HarmonyOS NEXT）上把威胁尽量拔除。

原厂固件下的处理顺序：**职责明确的运营商 DM/自注册 → 独立扫描引擎 → 统计与诊断日志 → 与权限、安装及智能功能耦合的组件**。结合系统隐藏设置、ADB 停用/卸载、AppOps 剥权、基于独立 UID 的网络阻断与关键入口开源替换，逐项处理并保留回退路径。

实机记录基于个人**「双机物理隔离」**用法：
- **moto g100 国行（MYUI 8，不插卡）**：海外核心与高敏资产主力机。除首轮卸载 `RegService`、停用 `DeviceShield Engine` 与 `Xlog` 外，2026-11-20 完成全量 481 包排雷，新增停用 26 个联想/ZUI/国行常驻与遥测包，并对 7 个系统耦合 Checkin/安全包完成 AppOps 后台与统计剥权。
- **realme Neo7（ColorOS 17 / Android 17）**：国内日常软件专用机。除历史卸载 `SystemHelper` / `RegService` 与首轮停用 `DCS` 外，2026-11-20 将 3 项反诈/风控隐藏 Settings 开关置 `0`，新增停用包括中央遥测守护进程 `com.oplus.framework.network.drs` 在内的 33 个后台/画像/冗余包，并对 20 个受系统保护或核心耦合包完成 AppOps 剥权与后台清退。
