# 中国大陆国行 Android 手机系统组件“脱毒”方案

2026-11-17。本文整理运营商注册、统计日志、安装扫描与更新组件的公开资料，并记录两台手机的有限实操结果。适用范围为国行 Android/AOSP 固件及仍兼容 Android 包管理的华为系统；HarmonyOS NEXT 等非 Android 固件不在范围内。具体型号、构建、组件版本与用户空间都会影响结果。

优先评估职责明确的运营商 DM、自注册、独立扫描引擎和统计日志，再处理与权限、安装和智能功能耦合的部分。方案包含设置、ADB、必要时的 Root/Hook 和联网限制路径；按组件逐项操作并准备恢复。

实机记录包含 Neo7 从历史 Android 16 到当前 Android 17 的状态变化，以及 Moto 扫描引擎的历史侧载结果。本轮新增处理仅为 Neo7 的 DCS、Moto 的 Xlog 停用；没有新增卸载。长期使用和后续 OTA 仍未覆盖。

建议按以下顺序阅读：

1. [操作与验收指南](docs/guide.md)：检查、恢复、功能测试与更新后复查。
2. [品牌与组件对照](docs/components.md)：按品牌查组件、来源和处理边界。
3. [实机记录](docs/devices.md)：两台设备的操作和已验证范围。
4. [公开来源](docs/sources.md)：论文、官方说明、数据库和机型反馈。
5. [下一阶段候选 TODO](docs/guide.md#next-stage-todo)：联网控制、权限与子组件限制、开源替换及隔离等路线的验证目标；尚未实施或选定。

文档区分三种证据等级：**实操支持**有具体操作记录，但不代表覆盖所有功能或长期使用；**试验候选**有其他固件或数据库依据，目标机仍需验证；**发现项**仅有组件或行为线索，不能据此推断可安全删除。每次只处理一个组件，保留原状态并按实际用途回归。

维护检查：`python3 tools/check_publication.py`。该命令检查公开文件边界、本地链接和常见隐私线索，不连接手机或网络；提交前仍须人工审阅。维护范围见 [SPEC](SPEC.md)。
